# Build the first vertical slice for desktop

The first vertical slice will target desktop keyboard and pointer input. Its driving, Showroom, Valet Transfer, Dyno run, and Dyno Sheet interactions will be tuned and validated on desktop before touch controls and mobile performance become implementation goals.

The input and rendering architecture should still permit later touch mappings and quality settings, but mobile parity is explicitly outside the prototype's exit criteria. This keeps the first build focused on proving the core interaction loop and vehicle feel.
