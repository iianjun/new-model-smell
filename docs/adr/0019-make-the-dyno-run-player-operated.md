# Make the Dyno run player-operated

The Dyno Lab will require the visitor to align the Active Flagship on its rollers and hold the normal accelerator control while the vehicle is clamped in place. Wheel speed, rollers, cooling fans, physical gauges, sound, building vibration, and a comically long printed Dyno Sheet escalate with the run before the Model Dossier opens.

Benchmark values remain manually curated Benchmark Records and are not calculated or modified by virtual driving performance. The player-operated run is a presentation ritual that keeps the normal vehicle controls meaningful and makes benchmark viewing a physical destination experience rather than a proximity-triggered panel.
