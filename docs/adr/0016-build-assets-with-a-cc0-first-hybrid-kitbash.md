# Build assets with a CC0-first hybrid kitbash

New Model Motors will begin with a zero-cost vertical slice built from primitives and a coherent family of CC0 assets, using Kenney as the primary town and vehicle kit. Generic roads, buildings, street furniture, background vehicles, and prototype sounds may be sourced and adapted. Identity-bearing objects—the Inspector Cart, shared Model Vehicle, Dealership facades and signs, Dyno Lab, Drive-In, and comic props—will be custom-made, substantially modified, or commissioned only after the driving and destination loop proves enjoyable.

Editable `.blend` files remain the source of truth and optimized `.glb` files are web delivery artifacts. Every external asset keeps source and license provenance. Paid packs and signature commissions are deferred until the camera, controls, collisions, vehicle selection, and one Content Destination work together in a playable vertical slice.
