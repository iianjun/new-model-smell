# 05 — Transfer into a Flagship and Drive-Out

**What to build:** Let a visitor select a specific Flagship Model entirely through driving. Parking the Inspector Cart in the Valet Transfer Bay behind a displayed Model Vehicle triggers an excessively refined handover that clamps and stows the Cart, wakes the chosen Flagship, and gives the visitor control so they can manually Drive-Out into Motor Town.

**Blocked by:** 04 — Visit the OpenAI cutaway Showroom.

**Status:** complete

- [x] Every displayed Model Vehicle has a clearly marked and physically reachable Valet Transfer Bay behind it.
- [x] A transfer begins only when the Inspector Cart is sufficiently aligned inside a specific bay.
- [x] Floor guidance and clamps visibly correct the final Cart alignment before the handover.
- [x] Visitor steering is suspended during deterministic alignment and restored only after the selected Flagship is ready.
- [x] The handover machinery visibly packs the tiny Inspector Cart into the selected Flagship's exaggerated trunk rather than making it disappear without explanation.
- [x] The selected Model Vehicle wakes with clear visual and optional audio feedback.
- [x] The selected Flagship Model becomes the Active Flagship; a multi-model lineup never defaults incorrectly to the first vehicle.
- [x] Control transfers without opening a model-selection menu, reloading the scene, or changing camera language.
- [x] The visitor personally steers the Active Flagship through the Showroom exit to complete the Drive-Out.
- [x] The Model Vehicle feels faster and heavier than the Inspector Cart, turns more broadly, and permits a limited controllable drift while retaining the same controls.
- [x] Collisions and recovery remain non-destructive in the Model Vehicle.
- [x] A browser test deliberately selects a non-first displayed Flagship, completes the Drive-Out, and verifies the correct Active Flagship remains under control.
