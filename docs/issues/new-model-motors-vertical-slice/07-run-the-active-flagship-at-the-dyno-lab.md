# 07 — Run the Active Flagship at the Dyno Lab

**What to build:** Make the right destination plot a player-operated Dyno Lab. A visitor drives the Active Flagship onto visible rollers, receives alignment feedback, becomes clamped in place, and holds the normal accelerator to escalate a physical benchmark ritual until the machine prints a Dyno Sheet.

**Blocked by:** 05 — Transfer into a Flagship and Drive-Out.

**Status:** complete

- [x] The Dyno Lab is a visible, reachable physical destination on the right point of the triangular loop.
- [x] The Dyno communicates approach direction, roller placement, and valid alignment without requiring a separate instruction screen.
- [x] The Dyno refuses to start for the Inspector Cart or when no Active Flagship exists.
- [x] A correctly aligned Active Flagship is secured by visible wheel clamps before the run accepts acceleration.
- [x] The normal accelerator input advances the Dyno run while the vehicle remains physically contained.
- [x] Wheels, rollers, cooling fans, gauges, vibration, pixel effects, and optional sound escalate from one coordinated run-progress signal.
- [x] Releasing the accelerator pauses or safely reduces progress without failing or resetting the experience.
- [x] Virtual throttle performance does not generate, increase, decrease, or otherwise alter curated Benchmark Record values.
- [x] Completing the run prints a comically long physical Dyno Sheet and enters a stable sheet-ready state.
- [x] The Flagship, camera, and Dyno remain in the existing world without loading a separate benchmark scene.
- [x] A browser test performs alignment and a complete held-accelerator run, then observes the printed sheet becoming available.
